# Tasks

Every task is test-first: write the test, run it and watch it fail for the intended reason (a compile
error is not a red step), make it pass, then refactor. Each group ends with a `/simplify` pass on the
code it touched and a re-run of its tests. PostgreSQL tests use `test.RunTestPostgres` and
need Docker.
