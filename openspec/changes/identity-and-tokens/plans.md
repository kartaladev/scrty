# Identity and Tokens Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the four foundations every later scrty capability depends on — an identity vocabulary with consumer-implementable ports, safe-by-default password encoding, signed JWTs whose checks cannot be inverted, and signing keys that survive restarts, rotate, and stop cleanly.

**Architecture:** Five leaf packages in the core module, layered by dependency: `factor` (no imports) and `identity` (stdlib only) carry the vocabulary; `password` wraps `golang.org/x/crypto`; `signingkey` owns key lifecycle over a replaceable `KeyStore` port and publishes a `KeySource`; `token` composes `identity` + `signingkey` + jwx. Every default is a functional option or a port, and every wiring mistake is a construction error. Test doubles and the identity port conformance suite live in a new `test` module so no consumer's module graph sees them.

**Tech Stack:** Go 1.27 · `github.com/lestrrat-go/jwx/v4` (single JOSE stack) · `golang.org/x/crypto` (argon2, bcrypt, scrypt) · `github.com/stretchr/testify` · `go.uber.org/mock` (mockgen v0.6.0, `--typed`) · `go.uber.org/goleak` · `pkg/logsample` (from project-foundation)

## Global Constraints

Every task's requirements implicitly include this section.

- **Module:** `github.com/kartaladev/scrty`, `go 1.27`. CI runs Go 1.27. The floor rose from 1.26 in this change: jwx v4 handles JSON through `encoding/json/v2`, which is in the standard library from 1.27 and on 1.26 needs `GOEXPERIMENT=jsonv2` — a flag every consumer would inherit. Never set `GOEXPERIMENT` to work around a build failure here; it means the floor was not applied.
- **jwx v4 API shape** (v4 moved these from v3, so v3 examples found online will not compile): `jwk.Import` is generic — `jwk.Import[jwk.Key](raw)`; field access is `jwt.Get[T](tok, name)` / `jwk.Get[T](key, name)` or `Field(name)`, never `Get(name, &dst)`; iterate a set with `for _, key := range set.All()`; `jws.WithKeySet` requires a `kid` by default; validation errors are struct types (`jwt.TokenExpiredError{}`). HTTP JWKS retrieval lives in the `jwkfetch` companion and is not needed by this change — scrty's own keys are in process.
- **Core module dependency guard:** no framework, driver, scheduler or DI dependency. `go test -run TestModuleLayout -count=1 .` must stay green after every dependency change.
- **No scrty module may require `github.com/kartaladev/scrty/test`** — not even from a `_test.go` file. `TestConsumerModuleGraph` enforces it.
- **No exported `Mock*` type in any production file.** Mocks are generated by `mockgen --typed`, never hand-written, and land in a `_test.go` file (consumers inside the package) or a `<pkg>test` sibling package (consumers outside). Per `use-mockgen`.
- **Test-first, always:** red → green → refactor. Run the test and *watch it fail for the intended reason* before writing the implementation. A test never seen to fail proves nothing. Per `golang-tdd`.
- **Table tests use the `assert` closure form**, never `want`/`wantErr` fields; `t.Context()`, never `context.Background()`; a `ctx` modifier field on context-sensitive components. Two or more cases sharing a call shape *must* be one table. Per `table-test`.
- **Library design:** every behaviour has a safe default that needs no configuration; every default is replaceable through an option, port or hook; every godoc option names the default it replaces; every port says what the library uses when none is supplied; contradictory configuration fails at construction, not at first use.
- **Defect claims:** any claim that code is defective needs a failing test as proof. The "verify red against X" steps below are exactly that proof for each departure (D5, D6, D7, D10, D11).
- **The user reference is opaque:** stored, compared and returned byte-for-byte. Never parsed, trimmed, or case-folded. Same for role, organization and group identifiers.
- **Identifiers are not secrets; secrets come from `crypto/rand`.**
- **`sub` is the principal's username.** Settled with the user on 2026-09-17, resolving design.md's open question. The documented cost (a rename invalidates live tokens) is stated in godoc, not worked around.
- **Never copy, cite or name the predecessor** in code, tests, docs, commits or OpenSpec artifacts.

**Recorded during implementation** — three things Task 1 needed that this plan did not anticipate:

1. **Do not run `go mod tidy` in Step 1.2a.** Nothing imports jwx or `x/crypto` until Tasks 2 and 5, and `tidy` removes a requirement with no importer, silently undoing the step. Both land as `// indirect` and become direct at the first real import.
2. **`make check`'s `generate-check` had to be narrowed first.** It diffed `'*.sql' '*.json' '*.yaml' '*.yml'` alongside `'*.go'`, so any uncommitted config edit failed the gate as "stale generated output" — the exact false alarm the target's own comment rules out. Narrowed to `'*.go'`, since mockgen is the only generating tool and emits nothing else, and re-proved by injecting a stale line into a tracked `.go` file and watching `generate-check` exit non-zero.
3. **No rendered check can see a secret held in a `[]byte`; only a structural check can.** Step 3.1a's row asserted `NotContains(fmt.Sprintf("%#v", *p), "argon2id")`. Under `%#v` a `[]byte` field renders as `[]uint8{0x61, 0x72, ...}`, so that assertion passes *while the hash leaks*: adding `Password []byte` to `Principal` and mapping it left the test green. **The first fix was itself wrong.** It added `NotContains(rendered, fmt.Sprintf("%#v", hash))`, which is dead code: a standalone `[]byte` renders as `[]byte{...}` and never matches the `[]uint8{...}` printed inside a struct, so that assertion cannot fail. Measured both renderings in a scratch module to confirm. What actually holds: a **text** check catches a `string`-typed leak, and **only a structural check** — reject any `[]byte` field on the outward type — catches a `[]byte` one. So every later "no secret here" guard asserts on the type rather than on a rendering, and never compares two `%#v` renderings. See `identity`'s `assertNoPasswordHash` (text) and `TestPrincipalCarriesNoRawSecretMaterial` (structural). Both halves are re-proved by inversion whenever either is touched.
4. **`Details` ships without `Role` and `PasswordChangedAt` until Task 4, deliberately.** Design decision 2 lists both on `Details`; Tasks 3.1-3.7 leave both out, because nothing tests them yet and this plan's rule is that the next red test asks for the field. Task 4.5 (the first role name is primary) asks for `Role`, and Task 4.7 (`PasswordChangedAt` unchanged by either verb) asks for the other. Recorded because three independent reviewers read the absence as drift from a settled artifact. One question to settle when Task 4.5 lands rather than now: `Details.Role` and `AssignedRole.Primary` are two representations of one fact, so if the string is never the source of truth, decision 2 should drop it rather than the code carrying both.
5. **`make check` was not gating, and said so only by exit code.** `make lint` printed `2 issues` and exited **0**; every later target still ran. Cause, proven rather than guessed: `.SHELLFLAGS` requires GNU Make 3.82, macOS ships 3.81, which ignores it silently — `make` showed `shell opts: hBc`, with no `e`. Recipes therefore ran under a bare `-c`, so a `for` loop reported only its **last** iteration's status and a failure in any module but the last passed as success. This affected `vet`, `lint`, `test` and `vuln`. Fixed by setting the flags inside each looping recipe, which works on either version, and verified three ways: the gate now fails with findings present, aborts before later targets, and still passes when clean. **Consequence for this change's record:** any earlier "make check exit=0" is not evidence that the core module passed lint or govulncheck. The per-package `go test -race` runs reported throughout were direct invocations and stand on their own.
6. **The password encoder interface is `password.Encoder`, not `PasswordEncoder`.** Design decision 5 named it `PasswordEncoder`; `revive` rejects the stutter, and the settled artifact was amended rather than the gate suppressed. Nothing is tagged, so the rename was free. Recorded because it departs from a settled artifact.
7. **Departure D5 is REPRODUCED.** `defect-claims.md` requires a failing test, so here is the record.
   - **Test:** `TestBcryptNeverMatchesByTruncation/a_longer_password_sharing_the_stored_password's_first_72_bytes_does_not_match`, in `password/bcrypt_test.go`.
   - **Command:** `go test -count=1 -v -run TestBcryptNeverMatchesByTruncation ./password`
   - **Failing output, against `Match` with no length check:** `Should be false` — a 73-byte password whose first 72 bytes equal a stored 72-byte password verified as that password. An authentication bypass, reachable in live code, not inferred from documentation. `golang.org/x/crypto/bcrypt.CompareHashAndPassword` hashes only the first 72 bytes and applies no length check of its own.
   - **Fix:** refuse over-length input in both verbs. Proved by dissection rather than one combined inversion, because the two guards are not interchangeable: removing only the `Match` guard fails *only* the shared-prefix case (the bypass returns), while removing only the `Encode` guard fails *only* the over-length case and the bypass stays closed. So `Match` is the load-bearing half — a hash written before the check existed, or by another tool, is still on the other side of that comparison. A fourth run with `>=` in place of `>` failed only the 72-byte case, pinning the boundary.
8. **The `test` module needs a root package from the start.** `go vet ./...` exits non-zero where the pattern matches no packages, so an empty module breaks `make check` between Tasks 1.3 and 4.3. `test/doc.go` supplies it, and documents why nothing imports the module.
9. **Task 1.2's jwx requirement had been lost, and 1.2's own verification could not have noticed.** When Task 5 resumed, `go.mod`, `go.sum` and `go.work.sum` carried no `github.com/lestrrat-go/jwx/v4` at all, although 1.2 is ticked. That task's checks are `go build ./...` and `TestModuleLayout`, and both pass with or without a requirement that nothing imports yet, so neither could see the loss — the same hazard as deviation 1, one step further on. Restored at `signingkey`'s first real import of `jwk`. Note that `go get github.com/lestrrat-go/jwx/v4` is not sufficient on its own: `jwk/jwkbb` imports `github.com/valyala/fastjson`, and until `go get github.com/lestrrat-go/jwx/v4/jwk/jwkbb@v4.5.0` adds it, `go list -deps` fails and `TestModuleLayout` fails with `missing go.sum entry` rather than with a dependency verdict. The guard was re-run afterwards and accepts jwx. **Consequence:** a dependency task whose only verification is "the build still works" verifies nothing about a dependency with no importer. It needs a direct assertion on the module graph.
10. **Task 5.7 is a characterization test, so its red step is the inversion, not the first run.** No trimming, case folding or normalization ever existed in the encoders, so `TestPasswordsAreHashedExactlyAsGiven` was green the moment it was written — which on its own proves nothing. Seen-to-fail was established with a temporary `mangle(input)` probe threaded through all six `Encode`/`Match` entry points and varied three ways, each failing exactly the rows that target it, on all three encoders: `strings.ReplaceAll(s, "e\u0301", "\u00e9")` (simulating NFC, so no new dependency) failed both normalization rows; `strings.TrimSpace` failed both whitespace rows; `strings.ToLower` failed the case row. The control row ("the exact bytes match") was proven separately by making all three `Match` methods return false unconditionally, which failed only that row. The probe was built to compile — an inversion that breaks the build reports nothing.
11. **One of Task 5.7's rows was unfalsifiable as first written.** The row "a password may be entirely whitespace" stored `" \t "` and presented `"hunter2"`. Under the `TrimSpace` probe the stored value trims to `""` and the presented one stays `"hunter2"`, so they remain unequal and the row passed anyway — it could not fail for the reason it claimed. Rewritten so **both** sides are whitespace (`" \t "` against `"  "`), which trimming collapses into one credential; the row then fails under the probe. This is the same class as deviation 3: an assertion whose stated rationale and actual reach do not match.
12. **`WithArgon2idRandom` and `WithScryptRandom` did not exist, and Task 5.8 needs them.** Both encoders already held a `random io.Reader` field defaulting to `crypto/rand.Reader`, but no option reached it, so the salt source was a default a consumer could not replace — a `library-design.md` violation independent of the test that found it. Added to both, each naming its default in godoc and stating that a source which cannot deliver is reported rather than worked around, so the option cannot weaken the guarantee that every stored hash carries an unpredictable salt. bcrypt deliberately gets no such option: `x/crypto` generates the salt inside its own hashing call, so there is no source to replace and no read to fail, which is why 5.8 covers Argon2id and scrypt only.
13. **Task 5.8 uses a generated mock, following tasks.md where plans.md disagreed.** plans.md's Step 5.8 proposed a hand-written two-line `io.Reader`, on the grounds that `use-mockgen` governs interfaces we own; tasks.md asks for a mockgen-generated double. Resolved for tasks.md, on two grounds: `use-mockgen`'s reflect-mode branch exists precisely for interfaces declared elsewhere, and the generated mock buys an assertion the hand-written reader cannot make — `.Times(1)`, verified by the controller, proves `Encode` actually consulted the salt source, so an encoder that never reached for a salt fails the test instead of passing it. Generated with `mockgen --destination password/random_mock_test.go --package password_test --typed io Reader`; `go.uber.org/mock` is now a core-module test dependency, which `TestModuleLayout` accepts.
14. **plans.md's proposed inversion for Task 5.9 does not bite. REPRODUCED, and replaced.** The step said to add `if len(input) != 7 { return false }` to `argon2idEncoder.Match` and "confirm the decoy benchmarks collapse to near zero and the 10% check fails". Both benchmarks present `"wrong-password"`, 14 bytes, so the **reference** benchmark collapses too. Measured under that probe: `MatchStoredHashWrongPassword` 7.090n ±29%, `MatchDecoyWrongPassword` 7.910n ±58%, `MatchDecoyLongPassword` 9.170n ±36% — all three at nanosecond scale, so the stored-versus-decoy comparison still shows no meaningful gap and the described check does not fail. Replaced with `if len(input) > 72 { return false }`, which separates the pair it is supposed to: 4.693m ±2%, 4.647m ±2%, **7.500n** ±78% — the long-password benchmark collapses by a factor of ~6e5 while the other two hold. Command: `go test -run=^$ -bench BenchmarkMatch -benchtime=50x -count=6 ./password`, compared with `.bin/benchstat -col /name`.
15. **The stored-versus-decoy pair cannot be falsified from inside `Match`, and the record should say so rather than imply otherwise.** Both records carry identical parameters and run the identical code path by construction, so no mutation of `Match` makes one cheaper than the other; deviation 14's probe collapsed both together for exactly that reason. // Package factor names the first-factor kinds a login can use and the channels
```go
// they travel over. It is the sole owner of this vocabulary: multi-factor
// authentication, security policy and every other capability reference these
// values and define none of their own.
//
// Unknown kinds fail closed — they report no channel and are never exempt from
// a multi-factor requirement — so a caller that forgets to set the kind is
// enforced rather than waved through.
package factor

// Kind is the kind of first factor a caller authenticated with.
type Kind string

// The first-factor kinds scrty names.
const (
	Password  Kind = "password"
	MagicLink Kind = "magic-link"
	OIDC      Kind = "oidc"
	Basic     Kind = "basic"
	APIKey    Kind = "api-key"
)

// Channel is the medium a factor travels over. AuthenticatorApp is the channel
// of authenticator-app second factors such as TOTP, and Email is also the
// channel of email-delivered second factors; neither is reported by any
// first-factor kind other than MagicLink.
type Channel string

// The channels scrty names.
const (
	Knowledge        Channel = "knowledge"
	Email            Channel = "email"
	AuthenticatorApp Channel = "authenticator-app"
	Federated        Channel = "federated"
	Machine          Channel = "machine"
)

// Channel reports the channel k travels over, or the empty channel for a kind
// the library does not name.
func (k Kind) Channel() Channel {
	switch k {
	case Password, Basic:
		return Knowledge
	case MagicLink:
		return Email
	case OIDC:
		return Federated
	case APIKey:
		return Machine
	default:
		return ""
	}
}

// MFAExempt reports whether a login with this kind is exempt from a multi-factor
// requirement. Only OIDC and APIKey are exempt; every other kind, including the
// empty kind and kinds the library does not name, is enforced.
//
// Whether an exempt login is accepted for a user who requires MFA is the
// security-policy capability's decision, with its own options.
func (k Kind) MFAExempt() bool {
	return k == OIDC || k == APIKey
}
```

```go
// Package identity defines who a caller is inside scrty: the principal exposed
// to application code, the details a user store returns, and the ports through
// which a consumer supplies users, role privileges and the multi-factor
// requirement from their own data.
//
// A user reference is opaque and consumer-owned. scrty stores, compares and
// returns it byte-for-byte and never parses it, changes its case, trims it or
// derives meaning from its format. Role, organization and group identifiers
// follow the same rule.
package identity

import "time"

// UserID references a user in the consumer's own data. It is opaque: scrty
// never parses it.
type UserID string

// Kind distinguishes a human user from a machine caller. The zero value is
// KindUser, so a principal built without a kind is a human user.
type Kind uint8

// The principal kinds.
const (
	KindUser Kind = iota
	KindService
)

// AssignedRole is a role grant. StartDate, ValidUntil and SuperRole are carried
// as data; what they mean for access is the authorization capability's
// decision, not this package's.
type AssignedRole struct {
	ID         string
	Name       string
	Primary    bool
	SuperRole  bool
	StartDate  time.Time
	ValidUntil time.Time
}

// Privilege is one named privilege and whether it is granted.
type Privilege struct {
	Name    string
	Granted bool
}

// ResourcePrivileges are the privileges a role holds on one resource.
type ResourcePrivileges struct {
	Group      string
	Resource   string
	Privileges []Privilege
}

// Group is an organization grouping. scrty supplies no default.
type Group struct {
	ID       string
	Name     string
	Internal bool
}

// Organization is the organization a user belongs to. scrty supplies no
// default: a user with no organization has none.
type Organization struct {
	ID    string
	Name  string
	Group *Group
}

// Principal is the identity scrty exposes outward. It never carries the
// password hash.
type Principal struct {
	ID           UserID
	Name         string
	Username     string
	Roles        []*AssignedRole
	ActiveRole   *AssignedRole
	Organization *Organization
	Kind         Kind
	Scopes       []string
}

// IsService reports whether p is a machine caller.
func (p Principal) IsService() bool { return p.Kind == KindService }

// Details is the stored record a user loader returns. It carries the password
// hash and therefore never leaves the library's own call paths; use
// PrincipalFromDetails to obtain the outward identity.
//
// Active is false in the zero value: a loader that does not explicitly mark a
// user active reports them inactive.
type Details struct {
	ID                UserID
	Name              string
	Username          string
	Password          []byte
	Active            bool
	Roles             []*AssignedRole
	Role              string
	Organization      *Organization
	PasswordChangedAt time.Time
}

// PrincipalFromDetails maps stored details to the outward principal, dropping
// the password hash and setting the active role to the primary role when one is
// present. It returns nil for nil details.
func PrincipalFromDetails(d *Details) *Principal {
	if d == nil {
		return nil
	}

	p := &Principal{
		ID:           d.ID,
		Name:         d.Name,
		Username:     d.Username,
		Roles:        d.Roles,
		Organization: d.Organization,
	}
	for _, r := range d.Roles {
		if r != nil && r.Primary {
			p.ActiveRole = r
			break
		}
	}
	return p
}
```

```go
package identity

import (
	"context"
	"errors"

// ErrNoPrincipal is the value MustPrincipalFromContext panics with when the
// context carries no principal. A recovering caller identifies it with
// errors.Is.
var ErrNoPrincipal = errors.New("identity: no principal in context")

type principalContextKey struct{}

// WithPrincipal returns a copy of ctx carrying p.
func WithPrincipal(ctx context.Context, p *Principal) context.Context {
	return context.WithValue(ctx, principalContextKey{}, p)
}

// PrincipalFromContext returns the principal ctx carries, reporting whether one
// was present.
func PrincipalFromContext(ctx context.Context) (*Principal, bool) {
	p, ok := ctx.Value(principalContextKey{}).(*Principal)
	return p, ok && p != nil
}

// MustPrincipalFromContext returns the principal ctx carries and panics with
// ErrNoPrincipal when there is none.
//
// It is for handlers that run behind an authentication interceptor, where a
// missing principal is a wiring mistake rather than a runtime condition. A
// recovering caller identifies the panic with errors.Is(v, ErrNoPrincipal).
func MustPrincipalFromContext(ctx context.Context) *Principal {
	p, ok := PrincipalFromContext(ctx)
	if !ok {
		panic(ErrNoPrincipal)
	}
	return p
}
```

```go
// The credential types scrty names. Later authentication methods add their own.

	CredentialsJWT              CredentialsType = "jwt"

// credential has been used.

	Type() CredentialsType
	Cleanup() error
}

// UsernamePassword is a username and password presented together.

	Username string
	Password []byte
}
```

```go
package identity

import "context"

// Field names a user field an option can set. A provisioner writes exactly the
// fields whose option was applied, which NewUser.IsSet reports.
type Field uint8

// The user fields options can set.
const (
	FieldName Field = iota
	FieldEmail
	FieldRoles
	FieldOrganization
	FieldPassword
)

// NewUser carries the fields a Provision or Update call named, and which of
// them were named at all.
//
// Implementations decide what to write from IsSet, never from a value's
// emptiness, so an unnamed field is never wiped.
type NewUser struct {
	Name         string
	Email        string
	Roles        []string
	Organization *Organization
	Password     []byte

	set [5]bool
}

// IsSet reports whether the caller named f.
func (u *NewUser) IsSet(f Field) bool {
	if int(f) >= len(u.set) {
		return false
	}
	return u.set[f]
}

func (u *NewUser) mark(f Field) {
	if int(f) < len(u.set) {
		u.set[f] = true
	}
}

// UserOption names one field of a Provision or Update call.
type UserOption func(*NewUser)

// WithUserName names the display name. There is no default: an unnamed display
// name is left unchanged by Update and empty by Provision.
func WithUserName(name string) UserOption {
	return func(u *NewUser) { u.Name = name; u.mark(FieldName) }
}

// WithUserEmail names the email address. The email is passed through and is
// never used to look up or match a user.
func WithUserEmail(email string) UserOption {
	return func(u *NewUser) { u.Email = email; u.mark(FieldEmail) }
}

// WithUserRoles names the role names. The first name is the primary role.
func WithUserRoles(roles ...string) UserOption {
	return func(u *NewUser) { u.Roles = roles; u.mark(FieldRoles) }
}

// WithUserOrganization names the organization.
func WithUserOrganization(org *Organization) UserOption {
	return func(u *NewUser) { u.Organization = org; u.mark(FieldOrganization) }
}

// WithUserPassword names the already-hashed password. The hash is stored
// verbatim and is never hashed again.
func WithUserPassword(hash []byte) UserOption {
	return func(u *NewUser) { u.Password = hash; u.mark(FieldPassword) }
}

// ApplyUserOptions collects opts into a NewUser. Implementations of
// UserProvisioner call it to learn which fields the caller named.
func ApplyUserOptions(opts ...UserOption) *NewUser {
	u := &NewUser{}
	for _, opt := range opts {
		if opt != nil {
			opt(u)
		}
	}
	return u
}

// UserLoader loads users from the consumer's own store.
//
// scrty supplies no default implementation: a component that needs a UserLoader
// and is given none fails at construction with a MissingPortError.
type UserLoader interface {
	// LoadByUsername loads the user with this username, which is passed exactly
	// as presented — never trimmed or case-folded. A miss returns
	// ErrUserNotFound; any other failure returns an error that is not
	// ErrUserNotFound.
	LoadByUsername(ctx context.Context, username string) (*Details, error)
}

// RoleLoader resolves a role name to the privileges it grants.
//
// scrty supplies no default implementation.
type RoleLoader interface {
	// LoadPrivileges returns the resource privileges effective for role. A role
	// with no privileges returns ErrPrivilegesNotFound.
	LoadPrivileges(ctx context.Context, role string) ([]*ResourcePrivileges, error)
}

// UserProvisioner creates and amends users in the consumer's own store.
//
// Provision and Update are deliberately separate verbs rather than one upsert:
// an upsert would let a caller overwrite an existing account on its first call,
// which is the same takeover path as matching identities by email.
//
// scrty supplies no default implementation.
type UserProvisioner interface {
	// Provision creates a user. The username is required. A taken username
	// returns ErrUserExists and leaves the existing user unchanged; the
	// collision is decided by the write itself, not by a pre-flight read, so
	// concurrent calls for one username create exactly one user. The first role
	// name is primary and each occurrence of a name creates its own grant. The
	// password hash is stored exactly as given. The created user is active.
	// Errors never include the username.
	Provision(ctx context.Context, username string, opts ...UserOption) (*Details, error)

	// Update amends an existing user, writing only the fields whose option was
	// applied and leaving every other stored field unchanged. An unknown
	// username returns ErrUserNotFound and creates nothing. It returns the
	// complete stored record. It never changes PasswordChangedAt, including
	// when the password is written. Concurrent updates of one user are
	// serialized.
	Update(ctx context.Context, username string, opts ...UserOption) (*Details, error)
}

// MFARequirementLookup reports whether a user must use a second factor.
//
// The requirement is recorded with the user rather than with any enrolment, so
// removing an enrolment does not clear it. Callers fail closed on an error.
//
// scrty supplies no default implementation.
type MFARequirementLookup interface {
	Required(ctx context.Context, userID UserID) (bool, error)
}
```

```go
package identity

import "errors"

// The errors identity ports return, which callers identify with errors.Is.
var (
	// ErrUserNotFound is returned by a user loader for an unknown username and
	// by a provisioner's Update for an unknown user.
	ErrUserNotFound = errors.New("identity: user not found")

	// ErrUserExists is returned by Provision when the username is taken.
	ErrUserExists = errors.New("identity: user already exists")

	// ErrPrivilegesNotFound is returned by a role loader for a role that grants
	// no privileges.
	ErrPrivilegesNotFound = errors.New("identity: role privileges not found")

	// ErrMissingPort identifies the configuration error a component returns
	// when a port it cannot work without was not supplied.
	ErrMissingPort = errors.New("identity: required port not configured")
)

// MissingPortError is the configuration error a component returns at
// construction when a port it needs was not supplied. It names the port, so the
// consumer learns which one to wire.
//
// scrty never substitutes an in-memory or empty implementation for a missing
// port: a component that cannot work without one fails at construction rather
// than at first request.
type MissingPortError struct {
	Port string
}

// MissingPort returns the configuration error for an unsupplied port.
func MissingPort(port string) error { return &MissingPortError{Port: port} }

func (e *MissingPortError) Error() string {
	return "identity: no " + e.Port + " configured"
}

// Is reports that every MissingPortError matches ErrMissingPort.
func (e *MissingPortError) Is(target error) bool { return target == ErrMissingPort }
```

```go
package identitytest

import (
	"context"
	"sync"
	"time"

	"github.com/kartaladev/scrty/identity"
)

// InMemoryStore implements every identity port over process memory. It is safe
// for concurrent use: Provision decides a username collision under the same
// lock that performs the insert, and Update holds that lock across its whole
// read-modify-write, so concurrent updates of one user are serialized.
type InMemoryStore struct {
	mu       sync.Mutex
	byName   map[string]*identity.Details
	privs    map[string][]*identity.ResourcePrivileges
	mfa      map[identity.UserID]bool
	nextID   int
	loadErr  error
	privsErr error
	mfaErr   error
}

// NewInMemoryStore returns an empty store.
func NewInMemoryStore() *InMemoryStore {
	return &InMemoryStore{
		byName: make(map[string]*identity.Details),
		privs:  make(map[string][]*identity.ResourcePrivileges),
		mfa:    make(map[identity.UserID]bool),
	}
}

// SeedRole records the privileges a role grants.
func (s *InMemoryStore) SeedRole(_ context.Context, role string, p []*identity.ResourcePrivileges) error {
	s.mu.Lock()
	defer s.mu.Unlock()
	s.privs[role] = p
	return nil
}

// SeedMFARequired records whether a user must use a second factor. The
// requirement lives here, with the user, not with any enrolment.
func (s *InMemoryStore) SeedMFARequired(_ context.Context, id identity.UserID, required bool) error {
	s.mu.Lock()
	defer s.mu.Unlock()
	s.mfa[id] = required
	return nil
}

// FailLookups makes every MFA lookup return err, so a caller's fail-closed
// behaviour can be exercised.
func (s *InMemoryStore) FailLookups(err error) {
	s.mu.Lock()
	defer s.mu.Unlock()
	s.mfaErr = err
}

// LoadByUsername implements identity.UserLoader.
func (s *InMemoryStore) LoadByUsername(_ context.Context, username string) (*identity.Details, error) {
	s.mu.Lock()
	defer s.mu.Unlock()

	if s.loadErr != nil {
		return nil, s.loadErr
	}
	d, ok := s.byName[username]
	if !ok {
		return nil, identity.ErrUserNotFound
	}
	return cloneDetails(d), nil
}

// LoadPrivileges implements identity.RoleLoader.
func (s *InMemoryStore) LoadPrivileges(_ context.Context, role string) ([]*identity.ResourcePrivileges, error) {
	s.mu.Lock()
	defer s.mu.Unlock()

	if s.privsErr != nil {
		return nil, s.privsErr
	}
	p, ok := s.privs[role]
	if !ok || len(p) == 0 {
		return nil, identity.ErrPrivilegesNotFound
	}
	return p, nil
}

// Required implements identity.MFARequirementLookup.
func (s *InMemoryStore) Required(_ context.Context, id identity.UserID) (bool, error) {
	s.mu.Lock()
	defer s.mu.Unlock()

	if s.mfaErr != nil {
		return false, s.mfaErr
	}
	return s.mfa[id], nil
}

// Provision implements identity.UserProvisioner. The collision is decided by
// the insert under the lock, never by a preceding read that another call could
// interleave with.
func (s *InMemoryStore) Provision(
	_ context.Context, username string, opts ...identity.UserOption,
) (*identity.Details, error) {
	if username == "" {
		return nil, errEmptyUsername
	}

	u := identity.ApplyUserOptions(opts...)

	s.mu.Lock()
	defer s.mu.Unlock()

	if _, taken := s.byName[username]; taken {
		// The message never includes the username: on just-in-time
		// provisioning it is an email address.
		return nil, identity.ErrUserExists
	}

	s.nextID++
	d := &identity.Details{
		ID:           identity.UserID(itoa(s.nextID)),
		Username:     username,
		Name:         u.Name,
		Password:     u.Password,
		Organization: u.Organization,
		Active:       true,
	}
	// Each occurrence of a name creates its own grant; the first is primary.
	for i, name := range u.Roles {
		d.Roles = append(d.Roles, &identity.AssignedRole{
			ID:      "r-" + itoa(s.nextID) + "-" + itoa(i),
			Name:    name,
			Primary: i == 0,
		})
	}
	if len(d.Roles) > 0 {
		d.Role = d.Roles[0].Name
	}

	s.byName[username] = d
	return cloneDetails(d), nil
}

// Update implements identity.UserProvisioner.
func (s *InMemoryStore) Update(
	_ context.Context, username string, opts ...identity.UserOption,
) (*identity.Details, error) {
	u := identity.ApplyUserOptions(opts...)

	s.mu.Lock()
	defer s.mu.Unlock()

	d, ok := s.byName[username]
	if !ok {
		return nil, identity.ErrUserNotFound
	}

	if u.IsSet(identity.FieldName) {
		d.Name = u.Name
	}
	if u.IsSet(identity.FieldPassword) {
		d.Password = u.Password // PasswordChangedAt is deliberately untouched.
	}
	if u.IsSet(identity.FieldOrganization) {
		d.Organization = u.Organization
	}
	if u.IsSet(identity.FieldRoles) {
		d.Roles = rebuildRoles(d.Roles, u.Roles)
		if len(d.Roles) > 0 {
			d.Role = d.Roles[0].Name
		}
	}
	return cloneDetails(d), nil
}

// rebuildRoles applies the role rules: empty names are skipped, repeats collapse
// to their first occurrence, and when no name survives the stored grants are
// left untouched — nothing can strip every role through Update. A surviving name
// matching an existing grant keeps that grant's identifier, super-role flag and
// validity window; when the stored grants repeat a name, the first stored grant
// is the one reused.
func rebuildRoles(stored []*identity.AssignedRole, names []string) []*identity.AssignedRole {
	survivors := make([]string, 0, len(names))
	seen := make(map[string]bool, len(names))
	for _, n := range names {
		if n == "" || seen[n] {
			continue
		}
		seen[n] = true
		survivors = append(survivors, n)
	}
	if len(survivors) == 0 {
		return stored
	}

	existing := make(map[string]*identity.AssignedRole, len(stored))
	for _, r := range stored {
		if r != nil && existing[r.Name] == nil {
			existing[r.Name] = r
		}
	}

	rebuilt := make([]*identity.AssignedRole, 0, len(survivors))
	for i, n := range survivors {
		if prev := existing[n]; prev != nil {
			rebuilt = append(rebuilt, &identity.AssignedRole{
				ID:         prev.ID,
				Name:       prev.Name,
				Primary:    i == 0,
				SuperRole:  prev.SuperRole,
				StartDate:  prev.StartDate,
				ValidUntil: prev.ValidUntil,
			})
			continue
		}
		rebuilt = append(rebuilt, &identity.AssignedRole{Name: n, Primary: i == 0})
	}
	return rebuilt
}

func cloneDetails(d *identity.Details) *identity.Details {
	out := *d
	out.Password = append([]byte(nil), d.Password...)
	out.Roles = make([]*identity.AssignedRole, 0, len(d.Roles))
	for _, r := range d.Roles {
		rc := *r
		out.Roles = append(out.Roles, &rc)
	}
	return &out
}

var _ identity.UserProvisioner = (*InMemoryStore)(nil)
var _ identity.UserLoader = (*InMemoryStore)(nil)
```

```go
// Package password hashes and verifies passwords.
//
// Argon2id is the default algorithm; bcrypt and scrypt are available for
// consumers who need them. Every parameter is an option, and every option has a
// floor taken from the OWASP password-storage minimums — an encoder configured
// below its floor is a configuration error at construction, not a weaker hash
// at runtime.
//
// Matching performs the full key derivation the stored hash's parameters
// specify whether or not the password matches, so a caller can equalize the
// cost of a login for an unknown user by matching the presented password
// against a decoy hash produced by the same encoder. The authentication
// capability does exactly that.
//
// Passwords are hashed exactly as given: no trimming, case folding or Unicode
// normalization.
package password

import (
	"encoding/base64"
	"errors"
)

// Encoder hashes passwords and checks them against a stored hash.
type Encoder interface {
	// Encode hashes input with a fresh random salt.
	Encode(input string) ([]byte, error)

	// Match reports whether input produces encoded, deriving the key with the
	// parameters recorded in encoded rather than the encoder's current ones, so
	// hashes made with older parameters keep verifying. A malformed hash, or a
	// hash of another algorithm, reports no match rather than an error.
	Match(input string, encoded []byte) bool
}

// The errors encoder construction and encoding return.
var (
	// ErrWeakParameters is returned at construction when a parameter is below
	// its floor. The message names the parameter.
	ErrWeakParameters = errors.New("password: parameters below the supported floor")

	// ErrPasswordTooLong is returned by the bcrypt encoder for an input longer
	// than 72 bytes.
	ErrPasswordTooLong = errors.New("password: password exceeds the algorithm's maximum length")
)

var b64 = base64.RawStdEncoding
```

```go
package password

import (
	"crypto/rand"
	"crypto/subtle"
	"fmt"
	"io"
	"strconv"
	"strings"

	"golang.org/x/crypto/argon2"
)

// Argon2id parameter defaults.
const (
	defaultArgon2idMemory     uint32 = 64 * 1024 // 64 MiB, in KiB
	defaultArgon2idIterations uint32 = 1
	defaultArgon2idThreads    uint8  = 4
	defaultArgon2idSaltLen    int    = 16
	defaultArgon2idKeyLen     uint32 = 32
)

type argon2idEncoder struct {
	memory     uint32
	iterations uint32
	threads    uint8
	saltLen    int
	keyLen     uint32
	random     io.Reader
}

// Argon2idOption configures the Argon2id encoder.
type Argon2idOption func(*argon2idEncoder)

// WithArgon2idMemory sets the memory cost in KiB. Default: 65536 (64 MiB).
func WithArgon2idMemory(kib uint32) Argon2idOption {
	return func(e *argon2idEncoder) { e.memory = kib }
}

// WithArgon2idIterations sets the number of passes. Default: 1.
func WithArgon2idIterations(n uint32) Argon2idOption {
	return func(e *argon2idEncoder) { e.iterations = n }
}

// WithArgon2idThreads sets the parallelism. Default: 4.
func WithArgon2idThreads(n uint8) Argon2idOption {
	return func(e *argon2idEncoder) { e.threads = n }
}

// WithArgon2idSaltLength sets the salt length in bytes. Default: 16.
func WithArgon2idSaltLength(n int) Argon2idOption {
	return func(e *argon2idEncoder) { e.saltLen = n }
}

// WithArgon2idKeyLength sets the derived key length in bytes. Default: 32.
func WithArgon2idKeyLength(n uint32) Argon2idOption {
	return func(e *argon2idEncoder) { e.keyLen = n }
}

// WithArgon2idRandom replaces the source of salt bytes. Default: crypto/rand.
// Supplying a source weaker than crypto/rand weakens every hash this encoder
// produces; the option exists so tests can exercise a failing source.
func WithArgon2idRandom(r io.Reader) Argon2idOption {
	return func(e *argon2idEncoder) { e.random = r }
}

// NewArgon2idEncoder returns the default password encoder: Argon2id with 64 MiB
// of memory, 1 iteration, 4 threads, a 16-byte salt and a 32-byte key.
//
// Each parameter has an option above. Construction fails with ErrWeakParameters
// when a parameter is below the OWASP floor: memory of at least 46 MiB with at
// least 1 iteration, or at least 19 MiB with at least 2 iterations; at least 1
// thread; a salt of at least 16 bytes; a key of at least 32 bytes.
//
// Sizing: each concurrent verification allocates the configured memory — 64 MiB
// by default — so a login rate limit is what bounds total memory use.
func NewArgon2idEncoder(opts ...Argon2idOption) (Encoder, error) {
	e := &argon2idEncoder{
		memory:     defaultArgon2idMemory,
		iterations: defaultArgon2idIterations,
		threads:    defaultArgon2idThreads,
		saltLen:    defaultArgon2idSaltLen,
		keyLen:     defaultArgon2idKeyLen,
		random:     rand.Reader,
	}
	for _, opt := range opts {
		opt(e)
	}
	if err := e.validate(); err != nil {
		return nil, err
	}
	return e, nil
}

func (e *argon2idEncoder) validate() error {
	const (
		floorHighMemory uint32 = 46 * 1024 // 46 MiB with >= 1 iteration
		floorLowMemory  uint32 = 19 * 1024 // 19 MiB with >= 2 iterations
	)
	switch {
	case e.iterations >= 2 && e.memory >= floorLowMemory:
	case e.iterations >= 1 && e.memory >= floorHighMemory:
	default:
		return fmt.Errorf(
			"%w: memory %d KiB with %d iterations; need memory >= %d KiB with >= 1 iteration, or >= %d KiB with >= 2 iterations",
			ErrWeakParameters, e.memory, e.iterations, floorHighMemory, floorLowMemory)
	}
	if e.threads < 1 {
		return fmt.Errorf("%w: threads %d; need >= 1", ErrWeakParameters, e.threads)
	}
	if e.saltLen < 16 {
		return fmt.Errorf("%w: salt length %d; need >= 16", ErrWeakParameters, e.saltLen)
	}
	if e.keyLen < 32 {
		return fmt.Errorf("%w: key length %d; need >= 32", ErrWeakParameters, e.keyLen)
	}
	return nil
}

func (e *argon2idEncoder) Encode(input string) ([]byte, error) {
	salt := make([]byte, e.saltLen)
	if _, err := io.ReadFull(e.random, salt); err != nil {
		return nil, fmt.Errorf("password: read salt: %w", err)
	}
	key := argon2.IDKey([]byte(input), salt, e.iterations, e.memory, e.threads, e.keyLen)
	return []byte(fmt.Sprintf("argon2id$%d$%d$%d$%s$%s",
		e.memory, e.iterations, e.threads, b64.EncodeToString(salt), b64.EncodeToString(key))), nil
}

func (e *argon2idEncoder) Match(input string, encoded []byte) bool {
	parts := strings.Split(string(encoded), "$")
	if len(parts) != 6 || parts[0] != "argon2id" {
		return false
	}
	memory, err1 := strconv.ParseUint(parts[1], 10, 32)
	iterations, err2 := strconv.ParseUint(parts[2], 10, 32)
	threads, err3 := strconv.ParseUint(parts[3], 10, 8)
	salt, err4 := b64.DecodeString(parts[4])
	want, err5 := b64.DecodeString(parts[5])
	if err1 != nil || err2 != nil || err3 != nil || err4 != nil || err5 != nil || len(want) == 0 {
		return false
	}

	// The parameters come from the stored hash, so hashes produced with older
	// parameters keep verifying. The derivation runs in full whether or not the
	// password matches.
	got := argon2.IDKey([]byte(input), salt,
		uint32(iterations), uint32(memory), uint8(threads), uint32(len(want)))
	return subtle.ConstantTimeCompare(got, want) == 1
}

var _ Encoder = (*argon2idEncoder)(nil)
```

```go
package password

import (
	"fmt"

	"golang.org/x/crypto/bcrypt"
)

// bcryptMaxInput is bcrypt's input limit. Longer inputs are refused rather than
// silently truncated.
const bcryptMaxInput = 72

const defaultBcryptCost = 10

type bcryptEncoder struct{ cost int }

// BcryptOption configures the bcrypt encoder.
type BcryptOption func(*bcryptEncoder)

// WithBcryptCost sets the cost. Default: 10, which is also the floor.
func WithBcryptCost(cost int) BcryptOption {
	return func(e *bcryptEncoder) { e.cost = cost }
}

// NewBcryptEncoder returns a bcrypt encoder with a default cost of 10.
// Construction fails with ErrWeakParameters below cost 10.
//
// bcrypt hashes only the first 72 bytes of its input. This encoder refuses
// longer inputs outright — Encode returns ErrPasswordTooLong and Match reports
// no match — so a password sharing a stored password's first 72 bytes never
// matches by truncation.
func NewBcryptEncoder(opts ...BcryptOption) (Encoder, error) {
	e := &bcryptEncoder{cost: defaultBcryptCost}
	for _, opt := range opts {
		opt(e)
	}
	if e.cost < defaultBcryptCost {
		return nil, fmt.Errorf("%w: cost %d; need >= %d", ErrWeakParameters, e.cost, defaultBcryptCost)
	}
	return e, nil
}

func (e *bcryptEncoder) Encode(input string) ([]byte, error) {
	if len(input) > bcryptMaxInput {
		return nil, fmt.Errorf("%w: %d bytes; bcrypt accepts at most %d",
			ErrPasswordTooLong, len(input), bcryptMaxInput)
	}
	return bcrypt.GenerateFromPassword([]byte(input), e.cost)
}

func (e *bcryptEncoder) Match(input string, encoded []byte) bool {
	if len(input) > bcryptMaxInput {
		// Without this, bcrypt would compare only the first 72 bytes and a
		// longer input sharing that prefix would match.
		return false
	}
	return bcrypt.CompareHashAndPassword(encoded, []byte(input)) == nil
}

var _ Encoder = (*bcryptEncoder)(nil)
```

```go
// Package signingkey manages the asymmetric keys scrty signs tokens with.
//
// A key manager generates a key per configured algorithm, writes it to a key
// store before using it, reloads the store so a restart invalidates no token,
// rotates keys on a schedule, and stops publishing keys past their lifetime. It
// publishes the public keys as a JWK Set and implements KeySource, which the
// token package signs and verifies through.
//
// The default store is in-memory and lasts only as long as the process. A
// consumer supplies any KeyStore instead — a durable one, or one that seals the
// private bytes, which the store treats as opaque.
package signingkey

// Alg names a signature algorithm. It is a string alias so a consumer can pass
// an algorithm name through configuration without importing jwx.
type Alg = string

// The signature algorithms scrty supports. RS256 is the default.
const (
	RS256 Alg = "RS256"
	ES256 Alg = "ES256"
	EdDSA Alg = "EdDSA"
)

func supportedAlg(alg Alg) bool {
	switch alg {
	case RS256, ES256, EdDSA:
		return true
	default:
		return false
	}
}
```

```go
package signingkey

import (
	"context"
	"sort"
	"sync"
	"time"
)

// Record is one stored signing key.
//
// Private holds the private key as PKCS #8 DER, or whatever a decorating store
// turned that into. A store persists it exactly as given and never interprets
// it.
type Record struct {
	Kid       string
	Alg       Alg
	Private   []byte
	PublicJWK []byte
	CreatedAt time.Time
}

// KeyStore persists signing keys.
//
// With no store configured the key manager uses NewInMemoryKeyStore, which does
// not survive a restart. A consumer replaces it with any implementation, such
// as the durable stores from the persistence capability.
type KeyStore interface {
	// Store inserts rec, replacing any record with the same Kid.
	Store(ctx context.Context, rec Record) error

	// LoadAll returns every stored record, oldest first by CreatedAt.
	LoadAll(ctx context.Context) ([]Record, error)
}

type inMemoryKeyStore struct {
	mu      sync.RWMutex
	records map[string]Record
}

// NewInMemoryKeyStore returns a KeyStore that keeps records in process memory.
// It is the default, and it is not durable: a new process starts with no keys,
// so every token signed by the previous process stops verifying.
func NewInMemoryKeyStore() KeyStore {
	return &inMemoryKeyStore{records: make(map[string]Record)}
}

func (s *inMemoryKeyStore) Store(_ context.Context, rec Record) error {
	s.mu.Lock()
	defer s.mu.Unlock()
	s.records[rec.Kid] = rec
	return nil
}

func (s *inMemoryKeyStore) LoadAll(_ context.Context) ([]Record, error) {
	s.mu.RLock()
	defer s.mu.RUnlock()

	out := make([]Record, 0, len(s.records))
	for _, rec := range s.records {
		out = append(out, rec)
	}
	sort.SliceStable(out, func(i, j int) bool { return out[i].CreatedAt.Before(out[j].CreatedAt) })
	return out, nil
}
```

```go
package signingkey

import (
	"crypto"
	"crypto/ecdsa"
	"crypto/ed25519"
	"crypto/elliptic"
	"crypto/rand"
	"crypto/rsa"
	"crypto/x509"
	"encoding/base64"
	"encoding/json"
	"fmt"
	"time"

	"github.com/lestrrat-go/jwx/v4/jwk"
)

// rsaKeyBits is the modulus size for generated RSA keys.
const rsaKeyBits = 2048

// keyEntry is a key the manager holds.
type keyEntry struct {
	kid       string
	alg       Alg
	signer    crypto.Signer
	publicJWK jwk.Key
	createdAt time.Time
}

// generateKey mints a key for alg and returns it with its stored form. The kid
// is the RFC 7638 SHA-256 thumbprint of the public key, so two processes that
// generate the same key agree on its identifier and a kid can never collide
// with an unrelated key.
func generateKey(alg Alg, now time.Time) (*keyEntry, Record, error) {
	var signer crypto.Signer

	switch alg {
	case RS256:
		k, err := rsa.GenerateKey(rand.Reader, rsaKeyBits)
		if err != nil {
			return nil, Record{}, fmt.Errorf("signingkey: generate %s: %w", alg, err)
		}
		signer = k
	case ES256:
		k, err := ecdsa.GenerateKey(elliptic.P256(), rand.Reader)
		if err != nil {
			return nil, Record{}, fmt.Errorf("signingkey: generate %s: %w", alg, err)
		}
		signer = k
	case EdDSA:
		_, k, err := ed25519.GenerateKey(rand.Reader)
		if err != nil {
			return nil, Record{}, fmt.Errorf("signingkey: generate %s: %w", alg, err)
		}
		signer = k
	default:
		return nil, Record{}, fmt.Errorf("signingkey: unsupported algorithm %q", alg)
	}

	der, err := x509.MarshalPKCS8PrivateKey(signer)
	if err != nil {
		return nil, Record{}, fmt.Errorf("signingkey: marshal %s: %w", alg, err)
	}

	entry, err := entryFromSigner(signer, alg, now)
	if err != nil {
		return nil, Record{}, err
	}

	pubJSON, err := json.Marshal(entry.publicJWK)
	if err != nil {
		return nil, Record{}, fmt.Errorf("signingkey: marshal public jwk: %w", err)
	}

	return entry, Record{
		Kid:       entry.kid,
		Alg:       alg,
		Private:   der,
		PublicJWK: pubJSON,
		CreatedAt: now,
	}, nil
}

// entryFromSigner builds the in-memory entry: the public JWK carrying kid, alg
// and use "sig".
func entryFromSigner(signer crypto.Signer, alg Alg, createdAt time.Time) (*keyEntry, error) {
	pub, err := jwk.Import[jwk.Key](signer.Public())
	if err != nil {
		return nil, fmt.Errorf("signingkey: import public key: %w", err)
	}

	thumb, err := pub.Thumbprint(crypto.SHA256)
	if err != nil {
		return nil, fmt.Errorf("signingkey: thumbprint: %w", err)
	}
	kid := base64.RawURLEncoding.EncodeToString(thumb)

	if err := pub.Set(jwk.KeyIDKey, kid); err != nil {
		return nil, fmt.Errorf("signingkey: set kid: %w", err)
	}
	if err := pub.Set(jwk.AlgorithmKey, alg); err != nil {
		return nil, fmt.Errorf("signingkey: set alg: %w", err)
	}
	if err := pub.Set(jwk.KeyUsageKey, "sig"); err != nil {
		return nil, fmt.Errorf("signingkey: set use: %w", err)
	}

	return &keyEntry{kid: kid, alg: alg, signer: signer, publicJWK: pub, createdAt: createdAt}, nil
}

// entryFromRecord decodes a stored record. A record that cannot be decoded is
// an error, never a skip: skipping it would mint a fresh key and orphan every
// token the unreadable key signed.
func entryFromRecord(rec Record) (*keyEntry, error) {
	key, err := x509.ParsePKCS8PrivateKey(rec.Private)
	if err != nil {
		return nil, fmt.Errorf("signingkey: decode key %q: %w", rec.Kid, err)
	}
	signer, ok := key.(crypto.Signer)
	if !ok {
		return nil, fmt.Errorf("signingkey: decode key %q: not a signer", rec.Kid)
	}
	entry, err := entryFromSigner(signer, rec.Alg, rec.CreatedAt)
	if err != nil {
		return nil, fmt.Errorf("signingkey: decode key %q: %w", rec.Kid, err)
	}
	return entry, nil
}
```

```go
// Option configures a KeyManager.
type Option func(*KeyManager)

// Clock is the time source. Default: the system clock.
type Clock interface{ Now() time.Time }

type systemClock struct{}

func (systemClock) Now() time.Time { return time.Now() }

// WithAlgs sets the algorithms a key is kept for. Default: RS256.
func WithAlgs(algs ...Alg) Option { return func(km *KeyManager) { km.algs = algs } }

// WithLifetime sets how long a key stays published after creation. Default: 24h.
// It must be longer than the rotation interval.
func WithLifetime(d time.Duration) Option { return func(km *KeyManager) { km.lifetime = d } }

// WithRotateInterval sets how often a new key is minted. Default: 1h.
func WithRotateInterval(d time.Duration) Option { return func(km *KeyManager) { km.rotateEvery = d } }

// WithHousekeepingInterval sets how often expired keys stop being published.
// Default: 1h.
func WithHousekeepingInterval(d time.Duration) Option {
	return func(km *KeyManager) { km.housekeepEvery = d }
}

// WithReloadInterval sets how often the store is reloaded, which is how
// replicas sharing a store see each other's keys. Default: 1m. It must be
// shorter than the rotation interval, or a replica would miss a rotation.
func WithReloadInterval(d time.Duration) Option {
	return func(km *KeyManager) { km.reloadEvery = d }
}

// WithKeyStore sets where keys are persisted. Default: NewInMemoryKeyStore,
// which does not survive a restart.
func WithKeyStore(s KeyStore) Option { return func(km *KeyManager) { km.store = s } }

// WithClock sets the time source. Default: the system clock.
func WithClock(c Clock) Option { return func(km *KeyManager) { km.clock = c } }

// WithLogger sets where rotation and reload failures are logged. Default:
// slog.Default(). Repeated failures are sampled, and each record written states
// how many were suppressed before it.
func WithLogger(l *slog.Logger) Option { return func(km *KeyManager) { km.logger = l } }

// WithErrorHook sets a function called with every rotation and reload failure.
// Default: none. Use it to surface a store outage that would otherwise leave one
// key signing indefinitely.
func WithErrorHook(fn func(error)) Option { return func(km *KeyManager) { km.errorHook = fn } }

func (km *KeyManager) validate() error {
	for _, alg := range km.algs {
		if !supportedAlg(alg) {
			return fmt.Errorf("signingkey: unsupported algorithm %q", alg)
		}
	}
	for _, d := range []struct {
		name  string
		value time.Duration
	}{
		{"lifetime", km.lifetime},
		{"rotate interval", km.rotateEvery},
		{"housekeeping interval", km.housekeepEvery},
		{"reload interval", km.reloadEvery},
	} {
		if d.value <= 0 {
			return fmt.Errorf("signingkey: %s must be positive, got %s", d.name, d.value)
		}
	}
	if km.lifetime <= km.rotateEvery {
		return fmt.Errorf(
			"signingkey: lifetime %s must be longer than the rotate interval %s, "+
				"or a key would stop being published while tokens it signed are still valid",
			km.lifetime, km.rotateEvery)
	}
	if km.reloadEvery >= km.rotateEvery {
		return fmt.Errorf(
			"signingkey: reload interval %s must be shorter than the rotate interval %s, "+
				"or a replica would miss another replica's rotation",
			km.reloadEvery, km.rotateEvery)
	}
	return nil
}
```

```go
type KeyManager struct {
	mu      sync.RWMutex

	current map[Alg]string       // alg -> kid

	started   bool
	stopped   bool

	wg        sync.WaitGroup
}

// NewKeyManager returns a manager holding a current key for every configured
// algorithm, generating and storing one where the store has none.
//
// It starts no goroutine: call Start for rotation, reload and housekeeping.
//
// Defaults: RS256 only; a 24h key lifetime; rotation every 1h; housekeeping
// every 1h; reload every 1m; an in-memory store; the system clock;
// slog.Default(); no error hook. Every one is an Option above.
func NewKeyManager(opts ...Option) (*KeyManager, error) {
	km := &KeyManager{
		keys:           make(map[string]*keyEntry),
		current:        make(map[Alg]string),
		algs:           []Alg{RS256},
		lifetime:       24 * time.Hour,
		rotateEvery:    time.Hour,
		housekeepEvery: time.Hour,
		reloadEvery:    time.Minute,
		store:          NewInMemoryKeyStore(),
		clock:          systemClock{},
		logger:         slog.Default(),
	}
	for _, opt := range opts {
		opt(km)
	}
	if err := km.validate(); err != nil {
		return nil, err
	}

	ctx := context.Background()
	if err := km.loadFromStore(ctx); err != nil {
		return nil, err
	}
	if err := km.mintMissing(ctx); err != nil {
		return nil, err
	}
	return km, nil
}

// loadFromStore reads every record and holds it. A record that cannot be
// decoded fails construction.
func (km *KeyManager) loadFromStore(ctx context.Context) error {
	recs, err := km.store.LoadAll(ctx)
	if err != nil {
		return fmt.Errorf("signingkey: load keys: %w", err)
	}

	km.mu.Lock()
	defer km.mu.Unlock()

	for _, rec := range recs {
		entry, err := entryFromRecord(rec)
		if err != nil {
			return err
		}
		km.keys[entry.kid] = entry
	}
	km.repickCurrentLocked()
	return nil
}

// repickCurrentLocked chooses, per algorithm, the held key with the latest
// CreatedAt. A tie goes to the key seen later, which for a store's own ordering
// is the one it listed last. Callers hold km.mu.
func (km *KeyManager) repickCurrentLocked() {
	km.current = make(map[Alg]string, len(km.algs))
	best := make(map[Alg]time.Time, len(km.algs))

	for kid, entry := range km.keys {
		if cur, ok := best[entry.alg]; !ok || !entry.createdAt.Before(cur) {
			best[entry.alg] = entry.createdAt
			km.current[entry.alg] = kid
		}
	}
}

// mintMissing generates and stores a key for every configured algorithm with no
// current key. The write happens before the key becomes current.
func (km *KeyManager) mintMissing(ctx context.Context) error {
	for _, alg := range km.algs {
		km.mu.RLock()
		_, have := km.current[alg]
		km.mu.RUnlock()
		if have {
			continue
		}
		if _, err := km.mintAndStore(ctx, alg); err != nil {
			return err
		}
	}
	return nil
}

// mintAndStore generates a key, writes it to the store, and only then holds it
// and makes it current.
func (km *KeyManager) mintAndStore(ctx context.Context, alg Alg) (string, error) {
	entry, rec, err := generateKey(alg, km.clock.Now())
	if err != nil {
		return "", err
	}
	if err := km.store.Store(ctx, rec); err != nil {
		return "", fmt.Errorf("signingkey: store %s key: %w", alg, err)
	}

	km.mu.Lock()
	defer km.mu.Unlock()
	km.keys[entry.kid] = entry
	km.current[alg] = entry.kid
	return entry.kid, nil
}

// SupportedAlgs reports the configured algorithms.
func (km *KeyManager) SupportedAlgs() []Alg {
	return append([]Alg(nil), km.algs...)
}

// GetSigner returns the key currently signing for alg.
func (km *KeyManager) GetSigner(alg Alg) (string, crypto.Signer, bool) {
	km.mu.RLock()
	defer km.mu.RUnlock()

	kid, ok := km.current[alg]
	if !ok {
		return "", nil, false
	}
	entry, ok := km.keys[kid]
	if !ok {
		return "", nil, false
	}
	return kid, entry.signer, true
}

// JWKS returns the public part of every key held, each with its kid, alg and
// use "sig". No entry carries private material.
func (km *KeyManager) JWKS() (jwk.Set, error) {
	km.mu.RLock()
	defer km.mu.RUnlock()

	set := jwk.NewSet()
	for _, entry := range km.keys {
		if err := set.AddKey(entry.publicJWK); err != nil {
			return nil, fmt.Errorf("signingkey: build jwks: %w", err)
		}
	}
	return set, nil
}
```

**Concurrency contract (fixes four named failure classes):**
- `lifecycle` mutex guards `started`, `stopped`, `cancel` and `wg`; the keyring `mu` guards `keys` and `current`. A loop never takes `lifecycle`, so `Stop` may hold it across `wg.Wait()` — that is what makes concurrent `Start`/`Stop` safe.
- Every loop exits with `return`, never `break`: a `break` inside `select` leaves only the `select` and the goroutine spins forever.
- Housekeeping takes the keyring lock itself and is only ever called from its own loop, never from rotation while rotation holds that lock.
- `Stop` cancels, then waits, so an in-flight generate-and-store finishes before `Stop` returns.

```go
// Start launches the rotation, reload and housekeeping loops. It is idempotent:
// starting an already-started manager launches nothing and returns nil, and
// starting a stopped manager launches nothing.
//
// The loops end when ctx is cancelled or Stop is called.
func (km *KeyManager) Start(ctx context.Context) error {
	km.lifecycle.Lock()
	defer km.lifecycle.Unlock()

	if km.started || km.stopped {
		return nil
	}

	loopCtx, cancel := context.WithCancel(ctx)
	km.cancel = cancel
	km.started = true

	km.wg.Add(3)
	go km.loop(loopCtx, km.rotateEvery, km.rotateAll)
	go km.loop(loopCtx, km.reloadEvery, km.reload)
	go km.loop(loopCtx, km.housekeepEvery, km.housekeep)

	return nil
}

// loop runs step every interval until the context ends. It returns rather than
// breaking: a break inside the select would leave the select but not the for,
// and the goroutine would spin until the process exits.
func (km *KeyManager) loop(ctx context.Context, every time.Duration, step func(context.Context)) {
	defer km.wg.Done()

	ticker := time.NewTicker(every)
	defer ticker.Stop()

	for {
		select {
		case <-ctx.Done():
			return
		case <-ticker.C:
			step(ctx)
		}
	}
}

// Stop ends the background work and returns once it has ended, including an
// in-flight key generation and store write — so no write lands after Stop
// returns. It is idempotent, and returns at once for a manager that was never
// started; a later Start then launches nothing.
func (km *KeyManager) Stop() error {
	km.lifecycle.Lock()
	defer km.lifecycle.Unlock()

	km.stopped = true
	if !km.started {
		return nil
	}

	km.cancel()
	km.wg.Wait() // safe under lifecycle: no loop ever takes this mutex
	km.started = false
	return nil
}
```

Add `reload` to `signingkey/rotate.go`:

```go
// reload publishes every stored key the manager does not already hold, skipping
// non-current keys older than the lifetime, then re-picks the current key per
// algorithm. A failure keeps the keys already held.
//
// This is what lets replicas sharing a store verify each other's tokens: without
// it, a key rotated in by one replica is rejected by every other until restart.
func (km *KeyManager) reload(ctx context.Context) {
	recs, err := km.store.LoadAll(ctx)
	if err != nil {
		km.report(ctx, "reload", "", err)
		return
	}

	now := km.clock.Now()

	km.mu.Lock()
	defer km.mu.Unlock()

	for _, rec := range recs {
		if _, held := km.keys[rec.Kid]; held {
			continue
		}
		if now.Sub(rec.CreatedAt) > km.lifetime && km.current[rec.Alg] != rec.Kid {
			continue // expired and not current: never republish it
		}
		entry, err := entryFromRecord(rec)
		if err != nil {
			km.report(ctx, "reload", rec.Alg, err)
			continue
		}
		km.keys[entry.kid] = entry
	}
	km.repickCurrentLocked()
}
```

Add `housekeep` to `signingkey/rotate.go`:

```go
// housekeep stops publishing every key created longer ago than the lifetime,
// except the current key of each algorithm. It takes the keyring lock itself
// and is only ever called from its own loop — never from rotation while that
// holds the lock.
//
// The store is not pruned: removal is from the in-memory set and the published
// JWKS only.
func (km *KeyManager) housekeep(context.Context) {
	now := km.clock.Now()

	km.mu.Lock()
	defer km.mu.Unlock()

	for kid, entry := range km.keys {
		if km.current[entry.alg] == kid {
			continue // the current key is kept however old it is
		}
		if now.Sub(entry.createdAt) > km.lifetime {
			delete(km.keys, kid)
		}
	}
}
```

```go
import (

// KeySource supplies signing keys and the verification key set. *KeyManager
// implements it.
//
// A consumer may supply any implementation instead — one backed by an external
// key service, for example — and the token package will issue and verify with
// its keys without a KeyManager ever being constructed.
type KeySource interface {
	// GetSigner returns the key currently signing for alg, reporting false when
	// there is none.
	GetSigner(alg Alg) (kid string, signer crypto.Signer, ok bool)

	// JWKS returns the public keys verification selects from, by kid.
	JWKS() (jwk.Set, error)
}

// LifetimeReporter is the optional half of KeySource: a source that knows how
// long its keys live and how often it rotates them lets a token generator
// refuse a token lifetime that would outlive the key signing it.
//
// A source that does not implement it simply gets no such check.
type LifetimeReporter interface {
	KeyLifetime() time.Duration
	RotateInterval() time.Duration
}

// KeyLifetime reports how long a key stays published after creation.
func (km *KeyManager) KeyLifetime() time.Duration { return km.lifetime }

// RotateInterval reports how often a new key is minted.
func (km *KeyManager) RotateInterval() time.Duration { return km.rotateEvery }

var (
	_ KeySource        = (*KeyManager)(nil)
	_ LifetimeReporter = (*KeyManager)(nil)
)
```

```go
// Package token issues and verifies signed JSON Web Tokens for an authenticated
// principal.
//
// The signing algorithm is pinned by the key: verification selects the key by
// the token's kid from the key source's current set and uses that key's
// algorithm, so a token whose header names a different algorithm — or none —
// never verifies. No option enables unsigned tokens.
//
// The subject is the principal's username. Renaming a user therefore
// invalidates their live tokens; renames also end their sessions.
//
// No exported signature here carries a jwx type: the public surface is
// crypto.Signer, the JWK Set, and this package's own claim accessors.
package token

import (
	"errors"

	"github.com/lestrrat-go/jwx/v4/jwt"
)

// ErrTokenInvalid identifies every rejection of a token. The specific cause is
// wrapped, so errors.Is(err, ErrTokenInvalid) answers "was this token
// refused?" while the wrapped error says why.
//
// A failure to obtain the key set is not a rejection: it is returned as itself
// and does not match ErrTokenInvalid.
var ErrTokenInvalid = errors.New("token: invalid")

// Claims are the claims of a token that has been verified.
type Claims struct {
	tok jwt.Token
}

// Subject reports the principal's username, as carried in sub.
func (c *Claims) Subject() string {
	sub, err := jwt.Get[string](c.tok, jwt.SubjectKey)
	if err != nil {
		return ""
	}
	return sub
}

// ID reports the token identifier the caller supplied at issue, as carried in
// jti. On the session path this is the session identifier.
func (c *Claims) ID() string {
	id, err := jwt.Get[string](c.tok, jwt.JwtIDKey)
	if err != nil {
		return ""
	}
	return id
}
```

```go
package token

import (
	"fmt"
	"time"

	"github.com/kartaladev/scrty/signingkey"
	"github.com/lestrrat-go/jwx/v4/jwt"
)

// Clock is the time source. Default: the system clock.
type Clock interface{ Now() time.Time }

type systemClock struct{}

func (systemClock) Now() time.Time { return time.Now() }

const defaultLifetime = 15 * time.Minute

type config struct {
	keys     signingkey.KeySource
	issuer   string
	audience string
	lifetime time.Duration
	alg      signingkey.Alg
	clock    Clock

	hasIssuer   bool
	hasAudience bool
}

// GenerateOption configures a Generator.
type GenerateOption func(*config)

// WithIssuer sets the iss claim of issued tokens, and the issuer the generator
// enforces when it verifies. Default: none, and iss is then not set.
func WithIssuer(iss string) GenerateOption {
	return func(c *config) { c.issuer = iss; c.hasIssuer = true }
}

// WithAudience sets the aud claim of issued tokens, and the audience the
// generator enforces when it verifies. Default: none, and aud is then not set.
func WithAudience(aud string) GenerateOption {
	return func(c *config) { c.audience = aud; c.hasAudience = true }
}

// WithLifetime sets how long an issued token is valid. Default: 15 minutes. A
// lifetime of zero or less is a configuration error.
func WithLifetime(d time.Duration) GenerateOption {
	return func(c *config) { c.lifetime = d }
}

// WithSigningAlg sets the algorithm to sign with. Default: RS256. The key
// source must hold a current key for it at issue time.
func WithSigningAlg(alg signingkey.Alg) GenerateOption {
	return func(c *config) { c.alg = alg }
}

// WithClock sets the time source for iat and exp. Default: the system clock.
func WithClock(clk Clock) GenerateOption { return func(c *config) { c.clock = clk } }

// VerifyOption configures a Verifier.
type VerifyOption func(*config)

// VerifyWithKeySource sets where verification keys come from. Required: there
// is no default, and constructing a verifier without it is a configuration
// error.
func VerifyWithKeySource(keys signingkey.KeySource) VerifyOption {
	return func(c *config) { c.keys = keys }
}

// VerifyWithIssuer enforces iss. Default: none, and iss is then not checked.
// Enforcement depends on whether this option was given, never on the
// configured value being non-empty.
func VerifyWithIssuer(iss string) VerifyOption {
	return func(c *config) { c.issuer = iss; c.hasIssuer = true }
}

// VerifyWithAudience enforces aud. Default: none, and aud is then not checked.
// When set, a token without aud is rejected.
func VerifyWithAudience(aud string) VerifyOption {
	return func(c *config) { c.audience = aud; c.hasAudience = true }
}

// VerifyWithClock sets the time source for every time check. Default: the
// system clock.
func VerifyWithClock(clk Clock) VerifyOption { return func(c *config) { c.clock = clk } }

func newConfig() *config {
	return &config{lifetime: defaultLifetime, alg: signingkey.RS256, clock: systemClock{}}
}

// validateOptions builds the jwt validation options. Expiry is registered here,
// exactly once: registering it twice would make a later change to the rule
// silently ineffective in one of the two places.
func (c *config) validateOptions() []jwt.ValidateOption {
	opts := []jwt.ValidateOption{
		// exp must be present; jwt.Validate rejects a passed exp by default,
		// with no skew tolerated.
		jwt.WithRequiredClaim(jwt.ExpirationKey),
		jwt.WithClock(jwt.ClockFunc(c.clock.Now)),
	}
	if c.hasIssuer {
		opts = append(opts, jwt.WithIssuer(c.issuer))
	}
	if c.hasAudience {
		opts = append(opts, jwt.WithAudience(c.audience))
	}
	return opts
}

func (c *config) validateLifetime() error {
	if c.lifetime <= 0 {
		return fmt.Errorf("token: lifetime must be positive, got %s", c.lifetime)
	}
	// When the key source reports both, a token must not outlive the key that
	// signed it: after `lifetime - rotateInterval` the signing key may already
	// have been unpublished.
	if r, ok := c.keys.(signingkey.LifetimeReporter); ok {
		if max := r.KeyLifetime() - r.RotateInterval(); c.lifetime > max {
			return fmt.Errorf(
				"token: lifetime %s exceeds the key source's usable window %s "+
					"(key lifetime %s minus rotate interval %s); tokens would outlive the key that signed them",
				c.lifetime, max, r.KeyLifetime(), r.RotateInterval())
		}
	}
	return nil
}
```

```go
package token

import (
	"context"
	"errors"
	"fmt"

	"github.com/lestrrat-go/jwx/v4/jwt"
)

// Verifier checks a token and returns its claims.
type Verifier interface {
	Verify(ctx context.Context, token string) (*Claims, error)
}

type verifier struct{ cfg *config }

// NewVerifier returns a Verifier. VerifyWithKeySource is required; every other
// option has a default named in its own documentation.
func NewVerifier(opts ...VerifyOption) (Verifier, error) {
	cfg := newConfig()
	for _, opt := range opts {
		opt(cfg)
	}
	if cfg.keys == nil {
		return nil, errors.New("token: no key source configured (VerifyWithKeySource is required)")
	}
	return &verifier{cfg: cfg}, nil
}

func (v *verifier) Verify(ctx context.Context, raw string) (*Claims, error) {
	return v.cfg.verify(ctx, raw)
}

func (c *config) verify(_ context.Context, raw string) (*Claims, error) {
	set, err := c.keys.JWKS()
	if err != nil {
		// Not a rejection of the token: the key set could not be obtained. This
		// deliberately does not match ErrTokenInvalid.
		return nil, fmt.Errorf("token: obtain key set: %w", err)
	}

	// The key is selected by the token's kid, and its own alg is used to check
	// the signature, so a header naming another algorithm — or none — fails.
	tok, err := jwt.Parse([]byte(raw),
		jwt.WithKeySet(set),
		jwt.WithValidate(true),
		jwt.WithValidateOption(c.validateOptions()...),
	)
	if err != nil {
		return nil, fmt.Errorf("%w: %w", ErrTokenInvalid, err)
	}
	return &Claims{tok: tok}, nil
}
```

```go
package token

import (
	"context"
	"fmt"

	"github.com/kartaladev/scrty/identity"
	"github.com/kartaladev/scrty/signingkey"
	"github.com/lestrrat-go/jwx/v4/jwa"
	"github.com/lestrrat-go/jwx/v4/jwk"
	"github.com/lestrrat-go/jwx/v4/jws"
	"github.com/lestrrat-go/jwx/v4/jwt"
)

// Generator issues tokens and verifies them with its own key source, issuer and
// audience, so a service that issues can verify without a second construction.
type Generator interface {
	Generate(ctx context.Context, id string, p *identity.Principal) (string, error)
	Verifier
}

type generator struct{ cfg *config }

// NewGenerator returns a Generator signing with keys.
//
// Defaults: no issuer; no audience; a 15-minute lifetime; RS256; the system
// clock. Each is a GenerateOption. Construction fails when the lifetime is zero
// or less, and when the key source reports a key lifetime and rotation interval
// that the token lifetime would outlive.
func NewGenerator(keys signingkey.KeySource, opts ...GenerateOption) (Generator, error) {
	if keys == nil {
		return nil, fmt.Errorf("token: no key source supplied")
	}
	cfg := newConfig()
	cfg.keys = keys
	for _, opt := range opts {
		opt(cfg)
	}
	if err := cfg.validateLifetime(); err != nil {
		return nil, err
	}
	return &generator{cfg: cfg}, nil
}

func (g *generator) Verify(ctx context.Context, raw string) (*Claims, error) {
	return g.cfg.verify(ctx, raw)
}

func (g *generator) Generate(_ context.Context, id string, p *identity.Principal) (string, error) {
	c := g.cfg

	kid, signer, ok := c.keys.GetSigner(c.alg)
	if !ok {
		// Never fall back to an unsigned token or another algorithm.
		return "", fmt.Errorf("token: no current key for algorithm %q", c.alg)
	}

	now := c.clock.Now()
	builder := jwt.NewBuilder().
		JwtID(id).
		Subject(p.Username). // the username, per the settled decision
		IssuedAt(now).
		Expiration(now.Add(c.lifetime))
	if c.hasIssuer {
		builder = builder.Issuer(c.issuer)
	}
	if c.hasAudience {
		builder = builder.Audience([]string{c.audience})
	}

	tok, err := builder.Build()
	if err != nil {
		return "", fmt.Errorf("token: build claims: %w", err)
	}
	payload, err := jwt.NewSerializer().Serialize(tok)
	if err != nil {
		return "", fmt.Errorf("token: serialize claims: %w", err)
	}

	// Import the signer as a JWK carrying the manager's kid, so the kid is
	// written into the JWS protected header and the verifier can select the key.
	key, err := jwk.Import[jwk.Key](signer)
	if err != nil {
		return "", fmt.Errorf("token: import signing key: %w", err)
	}
	if err := key.Set(jwk.KeyIDKey, kid); err != nil {
		return "", fmt.Errorf("token: set kid: %w", err)
	}

	alg, ok := jwa.LookupSignatureAlgorithm(c.alg)
	if !ok {
		return "", fmt.Errorf("token: unsupported algorithm %q", c.alg)
	}

	signed, err := jws.Sign(payload, jws.WithKey(alg, key))
	if err != nil {
		return "", fmt.Errorf("token: sign: %w", err)
	}
	return string(signed), nil
}
```

```go
				header := b64url(t, map[string]any{"alg": "HS256", "typ": "JWT", "kid": kid})
				claims := b64url(t, map[string]any{
					"sub": "alice",
					"jti": "s-1",
					"exp": time.Now().Add(time.Hour).Unix(),
				})
				mac := hmac.New(sha256.New, pubDER)
				mac.Write([]byte(header + "." + claims))
				sig := base64.RawURLEncoding.EncodeToString(mac.Sum(nil))
				return header + "." + claims + "." + sig
			},
		},
	}

	for _, tc := range cases {
		t.Run(tc.name, func(t *testing.T) {
			t.Parallel()

			keys := newKeySource(t)
			ver, err := token.NewVerifier(token.VerifyWithKeySource(keys))
			require.NoError(t, err)

			claims, err := ver.Verify(t.Context(), tc.token(t, keys))
			require.ErrorIs(t, err, token.ErrTokenInvalid)
			assert.Nil(t, claims)
		})
	}
}
```
